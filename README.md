## 🚀 Featured Projects

### 🖨️ [PrintEase](https://github.com/keerthana9966/printease) — *Live at [printease-smoky.vercel.app](https://printease-smoky.vercel.app/)*
> Campus print shop management system built for VNR VJIET

A **full-stack web app** that digitises the entire campus printing experience. Students upload documents, get instant cost quotes, pay via UPI, and track orders in real-time. Vendors get a live dashboard with a print queue, analytics, and one-click status management.

`Node.js` `Express` `MongoDB` `JWT Auth` `Cloudinary` `Multer` `Vercel`

`HTML` `CSS` `JavaScript` `Data Visualisation` `REST APIs`

`JavaScript` `NLP` `YouTube API` `AI/ML`
